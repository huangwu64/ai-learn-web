# 云服务器部署配置预留（V4）

> 此目录预留给**下个版本（V4）**迁移云服务器时使用。
> 当前版本**不填写任何默认配置**，仅作预留。

## 计划预留的配置项（V4 再填写）

- **服务器 IP / 域名**：后端服务对外地址
- **前端用户端 URL**：用户端访问地址（当前为 `/chat`，子路径方式，不占用根 URL）
- **HTTPS / 证书**：生产环境 TLS 配置
- **数据库远程地址**：云上 MySQL 连接信息
- **文件存储**：头像等上传文件的云存储路径（当前为本地 `uploads/` 目录）
- **CORS 白名单**：前端域名
- **环境变量**：JWT 密钥、API Key 等的生产环境注入方式

## 现状说明（V3.2）

- 根 URL `/` 为**综合入口**（PortalView），用户端在 `/chat`，管理后台在 `/admin`
- 头像上传存储在本地 `uploads/avatars/`，通过 `/uploads/**` 静态访问（开发环境由 Vite 代理到后端）
- API Key 存放在本地 `application-local.yml`（gitignore，不入库）或数据库 `ai_config` 表

**V4 时按需在本目录补充 `application-cloud.yml` 等配置文件。**
